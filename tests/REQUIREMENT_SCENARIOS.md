# Requirement scenarios

## A. Public project presentation

The README uses the paper title without reviewer packaging language. It remains identity-free,
places the existing Figure 1 exactly once immediately before Citation, retains the leaderboard
preview, links to the offline leaderboard, and provides valid relative links to the public exports
and diagnostic files.

## B. Leaderboard behavior

The site loads the Full-Coverage view from package-owned JSON and exposes all 17 systems with exact
overall and five-stage values. All, Proprietary, Open-weight reasoning, and Finance-specialized
filter pills combine with model search. Model and numeric columns sort in both directions, default
ordering is Overall descending, visible ranks update after every operation, and empty and
load-error states are explicit.

## C. Accessible responsive layout

The page uses one semantic table, accessible filter buttons and search, visible keyboard focus, a
skip link, live result status, and a horizontally scrollable table. Controls wrap without fixed
page widths at the 375 px viewport, reduced-motion preferences are respected, and the table header
may remain visible during vertical scrolling.

## D. Public export equivalence

Regeneration produces 5,110 records with the required columns. JSON, JSONL, CSV, and XLSX contain
the same IDs and values, and the export summary contains counts and file sizes only.

## E. Scientific reproduction

The public reproduction entry point and aggregate arithmetic reproduce the published public Gate,
selector, RQ1, and RQ2 results using frozen inputs without file-summary machinery.

## F. Release metadata scope

Tracked release metadata contains no file-content summaries or source version tokens. Dataset
structure, split boundaries, matrix alignment, feature dimensions, and
published result assertions remain covered.

## G. GitHub Pages deployment

The assembled site serves the same leaderboard at the repository Pages root and at
`leaderboard.html`. Stylesheets, scripts, aggregate JSON, visual assets, JSON and XLSX download
links, and repository documentation resolve within the deployed project subpath. All four public
data exports remain packaged, while no held-out item files are published.

## H. README scientific content

The README records the full, public, and held-out counts, the frozen difficulty bands, the
Context-Complete Reasoning Track, and the two nested diagnostics. It distinguishes structural
record completeness from detached parent evidence, lists all 17 leaderboard models, and describes
the matched Function-RAG, FunctionGraph-RAG, verification, and frozen public gate conditions.

## I. Minimal leaderboard presentation

The page has a centered FINEXAM-10K title, concise benchmark subtitle, 17-model metadata line,
restrained charcoal and low-saturation blue palette, ample white space, and no navigation chrome,
dashboard cards, shadows, gradients, decorative icons, or multiple tables. A compact Methodology
section follows the table and explains the native Direct baseline, scoring, and parse failures in
no more than three paragraphs.

## J. Anonymous static site and preview

Tracked site files and README contain no author or account identity, public repository or Pages
URL, email, institution, personal path, commit identifier, or SHA field. The leaderboard preview
is a PNG rendered from the finished page without text or EXIF metadata.
