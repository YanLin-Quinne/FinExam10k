\caption{GPT-4o program-of-thought variants on \textsc{FinExam-10K} ($N=10{,}198$), same
columns as Table~\ref{tab:r1-variants} plus \textbf{Rej.}, the number of generated programs the

prompt passes the two answer letters alone, 50 input tokens, and abstains on every conflict;
the informed prompt adds the question, the options, both programs and both execution results,
691 input tokens, and changes 434 answers for a net gain of 84 items ($p=1.5\times10^{-6}$ on

baseline is no longer significant.}
