Evaluation protocol

Methodology

The leaderboard reports the native Direct baseline. Each model answers the item as supplied, without external function retrieval, gold labels, or reference rationales.

Scores use exact answer-choice accuracy over a fixed denominator. Outputs that cannot be parsed to a valid option, including length-truncated responses, are scored as incorrect.
