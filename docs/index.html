Interventions

What the benchmark compares

Direct

The model answers from the item as supplied, without function retrieval.

Function-RAG

A retriever selects FinanceReasoning functions as structured support.

FunctionGraph-RAG

Retrieval expands through relations between functions before frozen selection.

FunctionGraph-RAG + Verifier

A post-execution verifier checks the selected PoT branch before finalizing its answer.

Selective Branch Router

A frozen public-trained pre-execution gate decides whether to invoke FunctionGraph-RAG after Direct and before branch execution. It never sees the gold answer or branch outcome.

Research scope

Transfer, then test

The retrieval structures and selectors are transferred from FinanceReasoning. FinExam-10K tests whether those frozen mechanisms improve professional examination reasoning.

Only aggregate held-out results appear here. Private records and per-item predictions are not loaded.

FinExam-10K is an independent academic benchmark.
